# SNG2S (SNG2GS) conversion investigation

## Goal

Investigate the output produced by the historical PC-98/MS-DOS SNG2S utility and use it as a reference when diagnosing differences in SNG-to-MIDI conversion. The investigation should not require audio playback.

## Local reference files

The files currently available in the user's local `R:\sng2s33` directory are:

- `SNG2S.EXE` — 32,383 bytes; dated 1993-08-03
- `SNG2S.DOC` — 8,316 bytes; dated 1993-08-03
- `README.DOC` — 865 bytes; dated 1993-08-03
- `sng2s33.lzh` — 21,660 bytes; archive dated 2026-10-11 locally
- `runner.MID` — 40,398 bytes; output generated on PC-98/MS-DOS 6.2 using SNG2S

The user reports that `Runner.sng` launched in Mimpi v4 without errors and that conversion with SNG2S succeeded. This makes the SNG2S-produced MIDI a useful comparison reference, but does not by itself prove which component is responsible for any conversion difference.

## Investigation plan

1. Read `SNG2S.DOC` and `README.DOC` locally; preserve the originals unchanged.
2. Parse `runner.MID` without playing audio. Record MIDI format, track count, division, tempo, event counts, note ranges, controllers, program changes, and end-of-track timing.
3. Compare those results with a MIDI generated by Jmplayer from the same SNG input, if available.
4. Identify concrete event-level differences before drawing conclusions about the converter.
5. Keep tests read-only and do not overwrite source files.
