## 現在の結論
- v1 のレイアウトは後続版と異なる。サイズ +80、length fields +115/+117、13個の相対 seek 値、ノート開始 +145 を支持する静的根拠があり、TEST.SNG でも容量条件が一致する。
- `SngConverter.cs` には `ReadLegacyV1Tempi()` がある。公開テスト `BalladeV1RunnerProducesReferenceTempoEvents()` は 500000 / 869000 / 869565 の参照 byte sequence を検査し、`BalladeV1KeepsDefaultTempoWhenTempoStreamIsUnchanged()` は変化しない tempo stream の既定値を検査する。
- SNG2S の静的解析では、raw tempo 37 と base tempo 120 から 69 BPM、粗い整数経路で 869000 µs/qn、192-tick grid 経路で 869565 µs/qn が得られる。tick 8 の pending-delta / absolute-tick の完全な因果関係は未解決。
- grid 構造の絶対 offset は記録間で不一致。0x00B5 (=181)、231、0x74+125 (=241) を同じ位置とみなさず、元データとの再照合までは未解決とする。
- `0x6EE = 4` は仮説であり、事実・実装条件として扱わない。
- MIMPIV4 の timer 初期化は確認済みだが、SNG tempo-record から playback timer への経路は未特定。SNG2S の MIDI-export 式を流用しない。
