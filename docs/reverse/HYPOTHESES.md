# 仮説・未解決事項

仮説は確認済み事実と混ぜず、検証条件を明記します。

## H-001 — v1 は v2 以降と異なるパートブロック構造を持つ可能性
**状態:** 有力候補・未確定

v1 runner.SNG では、既存の +81 / +112 / +114 / +116 / +158 前提はレイアウト検証に失敗する。一方、+80 / +115 / +117 / +119 / +161 の候補は全10パートで整合する。

**確認に必要なこと:**
- v1 の名前領域・ブロック境界・サイズ表の意味を独立に確認する。
- 参照 MIDI と各パートのイベントを照合する。
- 可能なら SNG2S の v1 分岐の逆アセンブルと一致させる。

## H-002 — Tie の Note-on 抑制と Note-off 延長規則
**状態:** Note-on 抑制は v2/v3 の参照データで強く支持。Note-off の所有ノート規則は一部未確定。

v2 `SHIZUME0` では非 Tie ノートレコード 2,713 件と SNG2GS Note-on 2,713 件が一致し、v3 `START__0` でも非 Tie レコード 5,362 件と SNG2GS Note-on 5,362 件が一致する。v4 には Tie bit 付きノートレコードがなく、Note-on/off は Glosa と参照 MIDI で一致する。現行 Glosa の余分な Note-on は v2 で944件、v3で127件で、いずれも追加 Note-off と対になっている。これを受け、Tie レコードは新しい Note-on/off を発生させず、一致する直前ノートを連続延長できる場合のみ Note-off を延長する実装に変更し、合成回帰テストを追加した。

**未解決:**
- 比較はトラック/チャンネルを無視した集計のため、同音高の重複や複数パートで Note-off がどのノートに属するかはまだ証明できていない。
- v2 参照 MIDI と Glosa MIDI の tick は160 ticks異なる。生成条件と理由は未確定。
- 参照 MIDI の作成に使われた SNG2GS/SNG2S の正確なバージョン・オプションは未確認。



補足観測（2026-10-19）: FUN_1000_3406 の静的解析記録では、展開済み内部レコードのフラグ +7 に対する 0xC0 マスクが 0x80 の場合、通常 Note-on 出力を迂回する分岐がある。これは Note-on 抑制と Note-off の期限管理が別経路である可能性を示すが、Tie の所有ノートや Note-off の対応規則は未確定。+7 は展開済み内部バッファのオフセットであり、生 SNG の byte 7 と同一視しない。

## H-007 — JMPlayer 実装と参照 MIDI の Tie 挙動の不一致

**状態:** ソース比較で不一致を確認、参照 MIDI の生成元は未確定

JMPlayer の `sngmidi.cpp` 267–292行と Glosa の現行実装は、Tie bit が立っている場合でも「直前のノートと音高が同じ」「前ノートの Note-off tick と現在の開始 tick が一致」の両条件を満たす場合にだけ Note-off を延長する。それ以外は新しい Note-on/Note-off を出す。一方、SHIZUME0 の参照 MIDI の Note-on は Tie bit が立っていない SNG レコードと一致する。

**含意:** 参照 MIDI がこの JMPlayer ロジックで生成されたと仮定するのは不適切。参照 MIDI の生成元実行ファイル・バージョン・オプションを確認するか、SNG2S/SNG2GS 側の Tie 処理を解析する必要がある。

## H-008 — v1 の +80 レイアウト候補と JMPlayer 実装の不一致

**状態:** 未解決

JMPlayer の `buildLayout`（`sngmidi.cpp` 96–147行）は全バージョンに同じ3つの header 候補、パートサイズ `entry+81`、長さフィールド `+112/+114/+116` を適用し、v1 専用の +80 分岐を持たない。対して runner.SNG では +80 / +115 / +117 / +119 / +161 の候補がデータ上整合するという過去の静的解析結果がある。

**確認に必要なこと:** JMPlayer が想定する v1 fixture と runner.SNG の差、候補計算、実際のパート境界、SNG2S の v1 処理を独立に照合する。データ上の整合性だけで新レイアウトを確定しない。
