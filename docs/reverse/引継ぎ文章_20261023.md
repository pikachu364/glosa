## 6. SNG v1 の解析メモ  
runner.SNG は 85,897 bytes。  
* tableEnd=114  
* legacy headerEnd=116  
* part 1 starts at 1510  
* +80：block size  
* +115 / +117：length fields  
* +119：13 seek values  
* record start +145：現在のモデルで 3,295 Note-on と 3,295 Note-off を数える  
SNG v1 tempo：  
* file offset 143 の base-tempo byte  
* tempo buffer は file offset 771（heap marker +10）  
* 参照 runner.MID tempo：tick 0 = 500,000、tick 8 = 869,000、tick 192 = 869,565 µs/qn  
SNG2S の静的解析では、base tempo 120・record value 37 から 69 BPM が得られる。整数丸め経路は観測値と整合するが、tick 8 の割り当てに関わる内部状態や 0x6EE の初期値は未確定。  
変換コードを根拠なく変更しないこと。  
## 7. MIMPIV4 のタイマー解析  
静的解析で確認できた経路：  
* FUN_1FF5_1344：driver dispatch  
* 選択された driver setup 分岐で 0x0438 → 0x0440 のコピー  
* FUN_1FF5_0D61：INT 8 handler の設定  
* FUN_1FF5_0DFA：timer divisor 計算と I/O port 書き込み  
ただし、SNG tempo record の第2 word が再生中に 0x0438、0x0440、0x7BF0 を更新する経路は未確認。  
次の調査は初期化経路を再発見することではなく、再生レコードの parser/caller と再生中の global 書き込みを追跡すること。必要な静的データが欠落している場合は、その制約を記録し、runtime trace が必要と明示する。  
SNG2S の MIDI 出力用 tempo 式を MIMPIV4 の実再生式と同一視しないこと。
