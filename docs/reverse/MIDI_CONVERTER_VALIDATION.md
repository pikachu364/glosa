# MIDI コンバーター比較検証

このページは、Sng2gs で生成した MIDI と、開発中の Glosa で生成した MIDI を、ユーザーの Windows PC 内で比較するための計画と進捗を記録します。

## 目的
- Sng2gs の実行・変換はユーザーが手元で行う。
- Glosa の開発版でも同じ入力 SNG を変換する。
- 検証ツールには SNG を渡さず、2つの MIDI だけを読み込ませる。
- 音符・タイミング・テンポ・制御イベントなどの差分を検出する。
- 著作権のある可能性があるデータはリポジトリへ追加せず、ローカルに保持する。

## 状態の定義
- **確認済み**: 実装またはテストを実際に実行し、結果を確認した。
- **実装済み・未実行**: コードは追加したが、この環境では Windows 上の実行結果を確認していない。
- **未着手**: まだ実装していない。
- **要注意**: 既知の制限があり、結果を最終的な正しさの証明として扱えない。

## 比較ツール初版の仕様
- 入力: MIDI ファイル A、MIDI ファイル B。
- 出力: PASS / FAIL、各ファイルの集計、差分カテゴリと件数。
- 入力ファイル名・パス、トラック名、テキストメタデータをレポートに含めない。
- 時刻は ticks-per-beat に依存しない quarter-note 単位へ正規化する。
- ノートは各トラック・チャンネル・音高ごとに FIFO で Note-on / Note-off を対応付ける。
- MIDI type 2 は初版では明示的に拒否する。
- SNG を読み込まず、Sng2gs を起動しない。ネットワーク送信機能も持たせない。

## 既知の制限
- MIDI の構造比較だけでは、元の SNG 仕様に対する正しさを証明できない。
- FIFO の Note-on/off 対応が、すべての重複音符表現に適するとは限らない。
- track name やテキストメタデータは比較対象から除外する。
- SysEx は内容を出力せず、初版では長さだけを比較する。
- 音源モジュール固有の音色や聴感は検証しない。
- 初版はコード追加段階であり、Windows 上での実行確認や自動テストは未完了。

## プライバシー運用
実際の SNG / MIDI、曲名、アーティスト名、個人のフルパス、保護された音符データはコミットしません。GitHub に記録するのはコード、自作 fixture、匿名化した集計結果、根拠を明示した進捗のみです。
