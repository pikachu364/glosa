# MIDI コンバート検証：進捗

## 目的
Sng2gs で変換した MIDI と、開発中の Glosa で変換した MIDI を Windows PC 内で比較し、コンバートの差分を見つける。Sng2gs の変換はユーザーが行い、検証ツールには MIDI だけを入力する。

## 進捗
| ID | 項目 | 状態 | 内容 |

| V-001 | 作業ブランチ | 完了 | `feature/midi-converter-validation` |
| V-002 | MIDI 比較 CLI 初版 | 実装済み・未実行 | 音符と MIDI イベントを比較 |
| V-003 | Windows セットアップ手順 | 作成済み・未実行 | README に記載 |
| V-004 | 自作 MIDI による自動テスト | 作成済み・未実行 | 一致、音高差、テンポ差、レポートのパス非出力 |
| V-005 | 比較精度の追加確認 | 未着手 | 破損 MIDI、重複音符、イベント差分の確認 |
| V-006 | 実データでのローカル検証 | 未着手 | SNG / MIDI は PC 内に保持 |

## 比較対象
- 音符の音高・チャンネル・ベロシティ・開始位置・長さ
- テンポ、プログラムチェンジ、コントロールチェンジ、ピッチベンド等
- SysEx 内容の一致（ハッシュで比較し、内容はレポートに出さない）
- PPQ の違いを正規化したイベント位置

トラック名・曲名などのテキスト、トラック順、トラック数は合否判定から除外する。変換器ごとに MIDI のトラック構成が異なる可能性があるため。

## 次に行うこと
1. 自作 MIDI の自動テストを実行し、結果を確認する。
2. 必要な差分検出を修正する。
3. Windows 上で、手元の SNG から作成した2つの MIDI を比較する。

## 注意
コードとテストは追加済みだが、まだ実行確認していない。PASS は2つの MIDI の一致を示すもので、SNG 仕様への正しさを単独で証明するものではない。実際の SNG / MIDI や曲名はコミットしない。
